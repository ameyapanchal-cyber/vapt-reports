## Report Structure

Every report covers:

- **Executive Summary** — risk rating, CVSS score, one-paragraph impact for a non-technical audience
- **Scope & Engagement Details** — what was tested, tools used, authorization reference
- **Vulnerability Details** — vulnerability ID, CVSS vector, CWE, OWASP category, steps to reproduce, proof of concept
- **Impact Assessment** — business impact table, full CVSS metric breakdown with rationale
- **Root Cause Analysis** — why the vulnerability exists at the code/architecture level
- **Remediation** — prioritised fixes (P1–P4), secure code examples, defence-in-depth
- **Appendices** — payload reference, tool notes, external references
